## Классы и наследование

```yl
‡ Животное ⟦
    ⋔ init(имя) ⟦ this.имя = имя ⟧
    ⋔ голос() ⟦ ^ "..." ⟧
⟧

‡ Собака † Животное ⟦
    ⋔ голос() ⟦ ^ "Гав!" ⟧
⟧

¤ р = ⇢ Собака("Рекс")
» р.имя + " говорит: " + р.голос()
```

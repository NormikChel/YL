## 변수

```yl
¤ x = 5
¤ 이름 = "안나"
¤ 숫자들 = [1, 2, 3]
¤ 사람 = ⟪"이름": "안나", "나이": 25⟫
```

타입 지정: `¤ x :int = 5`

## 조건문

```yl
? x > 5 ⟦
    » "5보다 큼"
⟧ ¿ ⟦
    » "5 이하"
⟧
```

## 반복문

```yl
@ i < 10 ⟦ i = i + 1 ⟧
# i = 0 .. 10 ⟦ » i ⟧
⇶ x = [1, 2, 3] ⟦ » x ⟧
```

## 함수

```yl
§ 더하기(a, b) ⟦ ^ a + b ⟧
```

## 클로저

```yl
¤ 두배 = λ (x) ⟦ ^ x * 2 ⟧
```

## 클래스

```yl
‡ 개 ⟦
    ⋔ init(이름) ⟦ this.이름 = 이름 ⟧
    ⋔ 짖기() ⟦ ^ "멍멍!" ⟧
⟧

¤ 멍멍이 = ⇢ 개("멍멍이")
```

## 제너레이터

```yl
§ 짝수(n) ⟦
    # i = 0 .. n ⟦ ? even(i) ⟦ ↤ i ⟧ ⟧
⟧

⇶ x = 짝수(10) ⟦ » x ⟧
```

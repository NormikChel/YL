# OOP

클래스, 상속, `this`, 메서드 오버라이드.

```yl
‡ 점 ⟦
    ⋔ init(x, y) ⟦
        this.x = x
        this.y = y
    ⟧
    ⋔ 길이() ⟦
        ^ sqrt(this.x * this.x + this.y * this.y)
    ⟧
⟧

¤ p = ⇢ 점(3, 4)
» "길이:", p.길이()   ~ 5
```

## 상속

```yl
‡ 동물 ⟦
    ⋔ init(이름 :str) ⟦ this.이름 = 이름 ⟧
    ⋔ 소리() ⟦ ^ "..." ⟧
⟧

‡ 개 † 동물 ⟦
    ⋔ 소리() ⟦ ^ "멍멍!" ⟧
⟧

¤ 멍멍이 = ⇢ 개("멍멍이")
» 멍멍이.이름 + " says: " + 멍멍이.소리()
```

출력: `멍멍이 says: 멍멍!`

# 예제

간단한 것부터 고급까지 YL 예제 모음.

## Hello world

```yl
» "안녕, 세상!"
```

## 클래스와 상속

```yl
‡ 동물 ⟦
    ⋔ init(이름) ⟦ this.이름 = 이름 ⟧
    ⋔ 소리() ⟦ ^ "..." ⟧
⟧

‡ 개 † 동물 ⟦
    ⋔ 소리() ⟦ ^ "멍멍!" ⟧
⟧

¤ 멍멍이 = ⇢ 개("멍멍이")
» 멍멍이.이름 + " says: " + 멍멍이.소리()
```

## 클로저와 map

```yl
¤ 제곱 = map([1, 2, 3, 4], λ (x) ⟦ ^ x * x ⟧)
» 제곱
```

## 제너레이터

```yl
§ 짝수(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = 짝수(10) ⟦
    » "짝수:", x
⟧
```

## 비동기

```yl
⚡ § 느림(x) ⟦ ^ x * 2 ⟧
¤ t = 느림(21)
» ⏸ t
```

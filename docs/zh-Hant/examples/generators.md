# 生成器 der

生成器用正港 **PHP Fiber** 實作 —— 這个是輕量級執行緒，不是假 der。

```yl
§ 偶數(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = 偶數(10) ⟦
    » "偶數：", x
⟧
```

輸出：

```
偶數：0
偶數：2
偶數：4
偶數：6
偶數：8
```

## 無限生成器

```yl
§ 計數器() ⟦
    ¤ i = 0
    @ ☑ ⟦
        ↤ i
        i = i + 1
    ⟧
⟧
```

::: tip 小編碎碎念
`@ ☑` 是無限迴圈 der，母湯直接跑喔。
:::

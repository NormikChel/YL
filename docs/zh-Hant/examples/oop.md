# 物件導向 der

類別、繼承、`this`、方法覆寫。

```yl
‡ 點 ⟦
    ⋔ init(x, y) ⟦
        this.x = x
        this.y = y
    ⟧
    ⋔ 長度() ⟦
        ^ sqrt(this.x * this.x + this.y * this.y)
    ⟧
⟧

¤ p = ⇢ 點(3, 4)
» "長度：", p.長度()   ~ 5
```

## 繼承

```yl
‡ 動物 ⟦
    ⋔ init(名字 :str) ⟦ this.名字 = 名字 ⟧
    ⋔ 叫聲() ⟦ ^ "..." ⟧
⟧

‡ 狗 † 動物 ⟦
    ⋔ 叫聲() ⟦ ^ "汪汪！" ⟧
⟧

¤ 小七 = ⇢ 狗("小七")
» 小七.名字 + " 說：" + 小七.叫聲()
```

輸出：`小七 說：汪汪！`

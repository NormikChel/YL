# 示例

YL 从简单到复杂的示例合集。

## Hello world

```yl
» "你好，世界！"
```

## 类与继承

```yl
‡ 动物 ⟦
    ⋔ init(名字) ⟦ this.名字 = 名字 ⟧
    ⋔ 叫声() ⟦ ^ "..." ⟧
⟧

‡ 狗 † 动物 ⟦
    ⋔ 叫声() ⟦ ^ "汪！" ⟧
⟧

¤ 小七 = ⇢ 狗("小七")
» 小七.名字 + " 说：" + 小七.叫声()
```

## 闭包与 map

```yl
¤ 平方 = map([1, 2, 3, 4], λ (x) ⟦ ^ x * x ⟧)
» 平方
```

## 生成器

```yl
§ 偶数(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = 偶数(10) ⟦
    » "偶数：", x
⟧
```

## 异步

```yl
⚡ § 慢(x) ⟦ ^ x * 2 ⟧
¤ t = 慢(21)
» ⏸ t
```

# 面向对象

类、继承、`this`、方法重写。

```yl
‡ 点 ⟦
    ⋔ init(x, y) ⟦
        this.x = x
        this.y = y
    ⟧
    ⋔ 长度() ⟦
        ^ sqrt(this.x * this.x + this.y * this.y)
    ⟧
⟧

¤ p = ⇢ 点(3, 4)
» "长度：", p.长度()   ~ 5
```

## 继承

```yl
‡ 动物 ⟦
    ⋔ init(名字 :str) ⟦ this.名字 = 名字 ⟧
    ⋔ 叫声() ⟦ ^ "..." ⟧
⟧

‡ 狗 † 动物 ⟦
    ⋔ 叫声() ⟦ ^ "汪！" ⟧
⟧

¤ 小七 = ⇢ 狗("小七")
» 小七.名字 + " 说：" + 小七.叫声()
```

输出：`小七 说：汪！`

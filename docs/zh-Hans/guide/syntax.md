# 语法

## 符号

| 符号 | 含义 |
|---|---|
| `¤` | 声明变量 |
| `§` | 定义函数 |
| `λ` | 闭包 |
| `»` | 打印 |
| `⟦ ⟧` | 代码块 |
| `?` / `¿` | 如果 / 否则 |
| `@` | while |
| `#` | for |
| `⇶` | foreach |
| `^` | return |
| `↤` | yield |
| `‼ ⁇ ⌦` | try/catch/finally |
| `⊕` | 导入 |
| `⊘ ↻` | break/continue |
| `☑ ☐ ∅` | true/false/null |
| `‡ ⋔ ⇢ †` | 类机制 |
| `⚡ ⏸` | 异步 / 等待 |

## 变量

```yl
¤ x = 5
¤ 名字 = "小七"
¤ 数字 = [1, 2, 3]
¤ 人 = ⟪"名字": "小七"⟫
```

带类型：`¤ x :int = 5`。

## 条件

```yl
? x > 5 ⟦
    » "大"
⟧ ¿ ⟦
    » "小"
⟧
```

## 循环

```yl
@ i < 10 ⟦ i = i + 1 ⟧
# i = 0 .. 10 ⟦ » i ⟧
⇶ x = [1, 2, 3] ⟦ » x ⟧
```

## 函数与闭包

```yl
§ 加法(a, b) ⟦ ^ a + b ⟧
¤ 翻倍 = λ (x) ⟦ ^ x * 2 ⟧
```

## 类

```yl
‡ 狗 ⟦
    ⋔ init(名字) ⟦ this.名字 = 名字 ⟧
    ⋔ 叫声() ⟦ ^ "汪！" ⟧
⟧

¤ 小七 = ⇢ 狗("小七")
```

## 生成器 / 异步

```yl
§ 偶数(n) ⟦ # i = 0 .. n ⟦ ? even(i) ⟦ ↤ i ⟧ ⟧ ⟧

⚡ § 慢(x) ⟦ ^ x * 2 ⟧
¤ t = 慢(21)
» ⏸ t
```

## 错误处理

```yl
‼ ⟦ ¤ r = 10 / 0 ⟧ ⁇ e ⟦ » e ⟧ ⌦ ⟦ » "完成" ⟧
```

# जेनरेटर

जेनरेटर असली **PHP Fiber** पर आधारित हैं — हल्के थ्रेड्स।

```yl
§ सम(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = सम(10) ⟦
    » "सम:", x
⟧
```

आउटपुट:

```
सम: 0
सम: 2
सम: 4
सम: 6
सम: 8
```

## अनंत जेनरेटर

```yl
§ काउंटर() ⟦
    ¤ i = 0
    @ ☑ ⟦
        ↤ i
        i = i + 1
    ⟧
⟧
```

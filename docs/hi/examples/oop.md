# OOP

क्लास, विरासत, `this`, मेथड ओवरराइड।

```yl
‡ बिंदु ⟦
    ⋔ init(x, y) ⟦
        this.x = x
        this.y = y
    ⟧
    ⋔ लंबाई() ⟦
        ^ sqrt(this.x * this.x + this.y * this.y)
    ⟧
⟧

¤ p = ⇢ बिंदु(3, 4)
» "लंबाई:", p.लंबाई()   ~ 5
```

## विरासत

```yl
‡ जानवर ⟦
    ⋔ init(नाम :str) ⟦ this.नाम = नाम ⟧
    ⋔ आवाज़() ⟦ ^ "..." ⟧
⟧

‡ कुत्ता † जानवर ⟦
    ⋔ आवाज़() ⟦ ^ "भौं भौं!" ⟧
⟧

¤ शेरू = ⇢ कुत्ता("शेरू")
» शेरू.नाम + " बोला: " + शेरू.आवाज़()
```

आउटपुट: `शेरू बोला: भौं भौं!`

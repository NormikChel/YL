# उदाहरण

सरल से उन्नत तक YL के उदाहरण।

## Hello world

```yl
» "नमस्ते, दुनिया!"
```

## क्लास और विरासत

```yl
‡ जानवर ⟦
    ⋔ init(नाम) ⟦ this.नाम = नाम ⟧
    ⋔ आवाज़() ⟦ ^ "..." ⟧
⟧

‡ कुत्ता † जानवर ⟦
    ⋔ आवाज़() ⟦ ^ "भौं भौं!" ⟧
⟧

¤ शेरू = ⇢ कुत्ता("शेरू")
» शेरू.नाम + " बोला: " + शेरू.आवाज़()
```

## क्लोज़र और map

```yl
¤ वर्ग = map([1, 2, 3, 4], λ (x) ⟦ ^ x * x ⟧)
» वर्ग
```

## जेनरेटर

```yl
§ सम(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = सम(10) ⟦
    » "सम:", x
⟧
```

## Async

```yl
⚡ § धीमा(x) ⟦ ^ x * 2 ⟧
¤ t = धीमा(21)
» ⏸ t
```

## वेरिएबल

```yl
¤ x = 5
¤ नाम = "अन्ना"
¤ संख्याएँ = [1, 2, 3]
¤ व्यक्ति = ⟪"नाम": "अन्ना", "उम्र": 25⟫
```

टाइप के साथ: `¤ x :int = 5`

## शर्तें

```yl
? x > 5 ⟦
    » "5 से बड़ा"
⟧ ¿ ⟦
    » "5 या कम"
⟧
```

## लूप

```yl
@ i < 10 ⟦ i = i + 1 ⟧
# i = 0 .. 10 ⟦ » i ⟧
⇶ x = [1, 2, 3] ⟦ » x ⟧
```

## फ़ंक्शन

```yl
§ जोड़(a, b) ⟦ ^ a + b ⟧
```

## क्लोज़र

```yl
¤ दोगुना = λ (x) ⟦ ^ x * 2 ⟧
```

## क्लास

```yl
‡ कुत्ता ⟦
    ⋔ init(नाम) ⟦ this.नाम = नाम ⟧
    ⋔ भौंक() ⟦ ^ "भौं भौं!" ⟧
⟧

¤ शेरू = ⇢ कुत्ता("शेरू")
```

## जेनरेटर

```yl
§ सम(n) ⟦
    # i = 0 .. n ⟦ ? even(i) ⟦ ↤ i ⟧ ⟧
⟧

⇶ x = सम(10) ⟦ » x ⟧
```

## Async

```yl
⚡ § धीमा(x) ⟦ ^ x * 2 ⟧

» ⏸ t
```

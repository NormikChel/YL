# サンプル

YL のサンプル集。簡単なものから高度なものまで。

## Hello world

```yl
» "こんにちは、世界！"
```

## クラスと継承

```yl
‡ 動物 ⟦
    ⋔ init(名前) ⟦ this.名前 = 名前 ⟧
    ⋔ 鳴き声() ⟦ ^ "..." ⟧
⟧

‡ 犬 † 動物 ⟦
    ⋔ 鳴き声() ⟦ ^ "ワン！" ⟧
⟧

¤ ポチ = ⇢ 犬("ポチ")
» ポチ.名前 + " が言う: " + ポチ.鳴き声()
```

## クロージャと map

```yl
¤ 二乗 = map([1, 2, 3, 4], λ (x) ⟦ ^ x * x ⟧)
» 二乗
```

## ジェネレータ

```yl
§ 偶数(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = 偶数(10) ⟦
    » "偶数:", x
⟧
```

## 非同期

```yl
⚡ § 遅い(x) ⟦ ^ x * 2 ⟧
¤ t = 遅い(21)
» ⏸ t
```

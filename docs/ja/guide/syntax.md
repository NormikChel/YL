# 構文

## 記号

| 記号 | 意味 |
|---|---|
| `~` | コメント |
| `¤` | 変数宣言 |
| `§` | 関数 |
| `λ` | ラムダ |
| `»` | 出力 |
| `⟦ ⟧` | ブロック |
| `?` / `¿` | if / else |
| `@` | while |
| `#` | for |
| `⇶` | foreach |
| `^` | return |
| `↤` | yield |
| `‼ ⁇ ⌦` | try / catch / finally |
| `⊕` | import |
| `⊘` / `↻` | break / continue |
| `☑` / `☐` / `∅` | true / false / null |
| `‡` | クラス |
| `⋔` | メソッド |
| `⇢` | new |
| `†` | 継承 |
| `⚡` / `⏸` | async / await |

## 変数

```yl
¤ x = 5
¤ 名前 = "アンナ"
¤ 数字 = [1, 2, 3]
¤ 人 = ⟪"名前": "アンナ", "年齢": 25⟫
```

型付き: `¤ x :int = 5`

## 条件分岐

```yl
? x > 5 ⟦
    » "5 より大きい"
⟧ ¿ ⟦
    » "5 以下"
⟧
```

## ループ

```yl
@ i < 10 ⟦ i = i + 1 ⟧
# i = 0 .. 10 ⟦ » i ⟧
⇶ x = [1, 2, 3] ⟦ » x ⟧
```

## 関数

```yl
§ 足す(a, b) ⟦ ^ a + b ⟧
```

## クロージャ

```yl
¤ 倍 = λ (x) ⟦ ^ x * 2 ⟧
```

## クラス

```yl
‡ 犬 ⟦
    ⋔ init(名前) ⟦ this.名前 = 名前 ⟧
    ⋔ 鳴く() ⟦ ^ "ワン！" ⟧
⟧

¤ ポチ = ⇢ 犬("ポチ")
```

## ジェネレータ

```yl
§ 偶数(n) ⟦
    # i = 0 .. n ⟦ ? even(i) ⟦ ↤ i ⟧ ⟧
⟧

⇶ x = 偶数(10) ⟦ » x ⟧
```

## 非同期

```yl
⚡ § 遅い(x) ⟦ ^ x * 2 ⟧
¤ t = 遅い(21)
» ⏸ t
```

## エラー処理

```yl
‼ ⟦ ¤ r = 10 / 0 ⟧ ⁇ e ⟦ » "捕捉:", e ⟧ ⌦ ⟦ » "finally" ⟧
```

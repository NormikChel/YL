# أمثلة

مجموعة من أمثلة YL من البسيط إلى المتقدم.

## Hello world

```yl
» "مرحباً بالعالم!"
```

## الفئات والوراثة

```yl
‡ حيوان ⟦
    ⋔ init(اسم) ⟦ this.اسم = اسم ⟧
    ⋔ صوت() ⟦ ^ "..." ⟧
⟧

‡ كلب † حيوان ⟦
    ⋔ صوت() ⟦ ^ "هوهو!" ⟧
⟧

¤ ريكس = ⇢ كلب("ريكس")
» ريكس.اسم + " يقول: " + ريكس.صوت()
```

## الإغلاقات و map

```yl
¤ مربعات = map([1, 2, 3, 4], λ (x) ⟦ ^ x * x ⟧)
» مربعات
```

## المولدات

```yl
§ زوجي(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = زوجي(10) ⟦
    » "زوجي:", x
⟧
```

## Async

```yl
⚡ § بطيء(x) ⟦ ^ x * 2 ⟧
¤ t = بطيء(21)
» ⏸ t
```

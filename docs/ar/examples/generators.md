# المولدات

المولدات تستخدم **PHP Fiber** حقيقية — خيوط خفيفة.

```yl
§ زوجي(n) ⟦
    # i = 0 .. n ⟦
        ? even(i) ⟦ ↤ i ⟧
    ⟧
⟧

⇶ x = زوجي(10) ⟦
    » "زوجي:", x
⟧
```

الناتج:

```
زوجي: 0
زوجي: 2
زوجي: 4
زوجي: 6
زوجي: 8
```

## مولد لا نهائي

```yl
§ عداد() ⟦
    ¤ i = 0
    @ ☑ ⟦
        ↤ i
        i = i + 1
    ⟧
⟧
```

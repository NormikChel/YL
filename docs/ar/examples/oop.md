# البرمجة الكائنية

الفئات، الوراثة، `this`، تجاوز الدوال.

```yl
‡ نقطة ⟦
    ⋔ init(x, y) ⟦
        this.x = x
        this.y = y
    ⟧
    ⋔ طول() ⟦
        ^ sqrt(this.x * this.x + this.y * this.y)
    ⟧
⟧

¤ p = ⇢ نقطة(3, 4)
» "الطول:", p.طول()   ~ 5
```

## الوراثة

```yl
‡ حيوان ⟦
    ⋔ init(اسم :str) ⟦ this.اسم = اسم ⟧
    ⋔ صوت() ⟦ ^ "..." ⟧
⟧

‡ كلب † حيوان ⟦
    ⋔ صوت() ⟦ ^ "هوهو!" ⟧
⟧

¤ ريكس = ⇢ كلب("ريكس")
» ريكس.اسم + " يقول: " + ريكس.صوت()
```

الناتج: `ريكس يقول: هوهو!`

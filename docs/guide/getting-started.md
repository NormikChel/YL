# Быстрый старт

## Что нужно

- **PHP 8.1+** (для Fibers и enum-match)
- **Composer** — опционально
- **Node 18+** — только если хочешь собрать эти доки

Проверка PHP:

```bash
php -v
```

## Установка

```bash
git clone https://github.com/your/yl.git
cd yl
```

Или просто положи `yl.php` в удобную папку.

## Первая программа

Создай файл `hello.yl`:

```yl
» "Привет, мир!"
```

Запусти:

```bash
php yl.php hello.yl
```

Вывод:

```
Привет, мир!
```

## Переменные

```yl
¤ имя = "Аня"
¤ возраст = 25
¤ флаг = ☑

» "Имя:", имя
» "Возраст:", возраст
» "Флаг:", флаг
```

## Функции

```yl
§ квадрат(x) ⟦
    ^ x * x
⟧

» квадрат(5)
```

`^` — это `return`. `§` — определение функции.

## REPL

```bash
php yl.php --repl
```

```
yl> ¤ x = 5
yl> x * 2
10
yl> x * x
25
yl> :vars
  x = 5
yl> :load test_json.yl
...
yl> выход
```

Команды REPL:

| Команда | Что делает |
|---|---|
| `:help` | Помощь |
| `:vars` | Показать переменные |
| `:load <файл>` | Выполнить `.yl`-файл |
| `выход` / `exit` / `:q` | Выйти |

## Playground
